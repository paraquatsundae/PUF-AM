MODULE: PUFAM (Ag Manager)
ROLE: Multi-enterprise farm / paddock management web app
STATUS: app (live on Cloud Run; Capacitor Android)

ONE-LINER
Multi-user Ag Manager for mixed farms — map paddocks and issues, farm diary, seasonal records, and optional crop packs (walnut blight first).

SYNOPSIS
- Ag Manager — multi-user farm management (public name PUFAM; repo folder still Walnut_farm_manager).
- Brand: PUFAM = PUF (Prototype Until Failure) + AM (Ag Manager). Formerly PUFOM / Orchard Manager.
- Supports orchard/tree, broadacre, hort, station/dairy/grazing, aquaculture (marron), and livestock overlay — skeleton expanding from walnut-first tools.
- Walnut crop pack (blight / chill / Ji methodology) is gated: only when farm profile or map areas include walnuts. New farms omit blight from default modules.
- Blight (when pack on): weather-driven infection-risk modelling tied to the farm diary and spray records; Ji et al. 2025 on a proxy wetness input — not LLM/AI predictions.
- Farm map: draw areas, pin field issues, optional offline basemap packs; issues feed into diary plans (Capacitor mobile path supported).
- Farm diary is system of record for sprays, irrigation, nutrition, and work.
- Also covers harvest/drying (dryer performance model), water budget from farm setup allocation, nutrition logging, financials, invite-PIN team auth.
- Stack: React/Vite/TypeScript, Firebase Firestore + Auth, DPIRD weather via server cache/Cloud Functions; deployed to Google Cloud Run (australia-southeast1).
- Does NOT control sprayers, ISOBUS, or vision — separate from the PUFworks cab stack (companion farm ops product under same PUF workshop brand).
